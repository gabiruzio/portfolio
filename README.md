# Portfolio Website

This project is a personal portfolio website developed as a college assignment for the Computer Science course.

The website was created to present personal projects, skills, and information in a modern and responsive interface.

## Features

- Responsive design
- Light and dark mode
- Language switch system
- Project showcase section
- Skills section
- Clean and modern interface

## Technologies Used

- HTML
- CSS
- JavaScript

## Development Requirements

One of the project requirements was to develop the entire website without using any libraries or frameworks.

All features and interface behaviors were implemented using only vanilla HTML, CSS, and JavaScript. Because apparently suffering builds character and "learning fundamentals" is academia’s favorite combat sport.

## Purpose

The main objective of this project is to practice front-end development concepts, responsive layouts, interface organization, and user experience features such as theme and language switching.

## Preview

The website adapts to different screen sizes and allows users to switch between:
- Light and dark themes
- Multiple languages
